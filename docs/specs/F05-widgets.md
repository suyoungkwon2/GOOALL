## 동작 상세
- iOS는 위젯 갱신 횟수를 제한한다. 스냅샷이 오래됐어도(updatedAt이 수 시간 전) 마지막 값을 그대로 보여준다.
- 스냅샷 갱신 주기는 1시간(F02)이므로 위젯 재요청도 1시간으로 맞춘다. 단계가 바뀌면 앱이 즉시 reload한다(F02-R5).
- 리셋 엔트리: 기간이 바뀌면 값 0·단계 0 상태를 미리 타임라인에 넣어 둔다 (앱 실행 없이도 리셋). ProgressEngine으로 만든다.
- 단계 전환 시 `.contentTransition` 등 가벼운 트랜지션 허용(위젯에서 지원되는 범위만). 수치 텍스트는 `.numericText`.
- 위젯 탭(R7): `widgetURL(gooall://today)` → 앱이 열리고 설정 시트·미리보기를 닫은 오늘 화면을 보여준다. 스킴은 `GOOALL/Info.plist`에 등록.
- 위젯 이미지는 메모리 한도가 낮다. 규격 해상도를 넘기지 않는다.
- 잠금화면은 MVP에서 텍스트 + 게이지로 확정. 미니 일러스트는 v0.2.
- 저장된 스냅샷의 기간이 이미 지났으면(앱을 오래 안 염) 현재 기간의 0 상태로 보여준다 (`ProgressEngine.timelineSnapshots`).
- 완료 문구(doneMessage)는 Large에만 표시한다. Medium은 높이가 낮아 완료 뱃지 + 수치만.
- 오버레이는 반투명 검은 캡슐 위에 표시해 이미지 밝기·라이트/다크와 상관없이 읽히게 한다.
- 위젯 화면 코드는 `Shared/GoalWidgetViews.swift`(앱의 렌더 테스트와 공용), 타임라인은 `widget/widget.swift`.

## 문구 (영어, F01 톤)
- 스냅샷 없음 (R8): **Hey, open GOOALL to set me up 👋**
- 위젯 갤러리 표시 이름: GOOALL / 설명: Watch your glow-up happen, one step at a time.
- 잠금화면 수치 형식: `{displayName}` + `6,240 / 10,000`
