# PRD — 제품 개요 (v0.1)

> 이 문서는 "왜, 누구를 위해, 어디까지"만 다룬다. 기능의 상세 동작은 `docs/specs/`가 원본이다. 여기에 동작 규칙을 복사하지 않는다 (두 곳이 어긋나는 걸 막기 위해).

## 문제와 컨셉
건강 앱은 숫자·링·그래프로 끝난다. 사람이 진짜 움직이는 이유는 "되고 싶은 모습"이다. 이 앱은 걸음 수 목표 달성률을 그 모습의 변화(식스팩, 맑은 안광 등)로 보여준다. 핵심 경험은 홈 화면의 큰 위젯. (운동 시간·수면 시간 지표는 v0.2)

## 타깃 사용자
- 귀엽고 개성 있는 걸 좋아하는 Gen Z. 앱 말투는 친구/언니 톤 (영어 우선, 문구 원본은 각 스펙의 "문구" 절)
- 걷기 습관을 만들고 싶지만 숫자 앱에는 동기가 안 붙는 사람
- 친구에게 홈 화면을 보여주며 "이거 봐 ㅋㅋ" 할 수 있는 사람 (공유 가능한 재미가 성장 동력)

## 성공 기준 (출시 후 확인)
- 설치 후 위젯을 홈 화면에 추가한 비율
- 7일 후에도 위젯이 홈 화면에 남아 있는 비율
- (스토어 평점/리뷰의 "재밌다" 언급)

## MVP 제외 (v0.2 이후 후보)
운동 시간·수면 시간 지표, 유료 테마(1회 구매), 주 시작 요일 사용자 설정, 다국어(한국어 등), 습관 관리 확장, 목표 여러 개 동시, 커스텀 테마, 소셜 공유, 잠금화면 배경 자동 변경(단축어), 잠금화면 미니 일러스트, Live Activity, 워치 앱, 주간 페이스 표시, 요일별 히스토리

## 수익화
MVP는 무료·무광고·계정 없음·서버 없음. v0.2에 테마를 1회 구매로 파는 모델을 도입할 예정이며, MVP부터 그 구조(테마 접근 권한 필드 + 잠금 판단 단일 지점)만 미리 만들어 둔다 — F04-R7.

## 제품 원칙
1. 숫자보다 그림. 위젯을 보는 순간 상태가 느껴져야 한다.
2. 0% 상태도 귀엽게. 자책을 유도하지 않는다.
3. 건강 효과를 주장하지 않는다. "동기부여용 재미 시각화".
4. 데이터는 기기 밖으로 나가지 않는다 (서버 없음).
