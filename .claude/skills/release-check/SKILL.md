# 출시 전 점검

qa 에이전트에게 위임해 아래를 확인하고, 결과를 체크리스트로 보고한다. 자동으로 확인할 수 없는 항목은 "사용자 확인 필요"로 표시한다.

## 코드·빌드
- [ ] Release 구성 빌드 성공, 경고 0 (또는 사유 명시)
- [ ] 단위 테스트 전부 통과
- [ ] 디버그 로그·테스트용 하드코딩 값 제거

## HealthKit·개인정보
- [ ] Info.plist `NSHealthShareUsageDescription` 문구가 구체적 ("걸음 수로 위젯 그림을 바꾸는 데 사용합니다")
- [ ] 쓰기 권한 요청 없음 (읽기만)
- [ ] 권한 거부 시 앱이 정상 동작하고 안내 표시
- [ ] 개인정보 처리방침 URL 준비 (사용자 확인 필요)
- [ ] App Store Connect 앱 개인정보 라벨: 건강 데이터 "수집 안 함(기기 내 처리)" 해당 여부 (사용자 확인 필요)

## 심사 가이드라인
- [ ] 건강 효과·의학적 주장 문구 없음 (앱 내, 스크린샷, 설명문)
- [ ] 성적·노골적 이미지 없음
- [ ] 위젯만 있고 앱이 빈약하지 않은지 — 앱 안에서도 오늘 화면·설정·테마 미리보기 제공

## 스토어 자료 (사용자 확인 필요)
- [ ] 앱 아이콘 1024px
- [ ] 스크린샷 6.9" / 6.5" — 위젯이 홈 화면에 있는 모습 포함
- [ ] 설명문, 키워드, 지원 URL

## 실기기
- [ ] 실제 걷기 후 1시간 내 위젯 단계 변경 확인 (사용자 확인 필요)
- [ ] 자정 리셋 확인 (사용자 확인 필요)
